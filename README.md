##  Installation & Usage

To view and test the project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/Geethika2123/mainflow-tasks.git
   cd mainflow-tasks
   ```
2. Open the main HTML file (e.g. `index.html`) in a browser (Chrome, Firefox, Edge).
3. Make changes in CSS / JS files and refresh the browser to see updates.
4. If you have live server or local web server (VSCode Live Server, etc), you can serve it to get proper paths for images, CSS.
